# 기능 요구사항

요구사항은 구현과 테스트가 쉽도록 기능 ID 단위로 정리합니다.

## 회원가입 및 계정 관리

| ID | 기능 | 요구사항 | 제약 | 예외 처리 |
| --- | --- | --- | --- | --- |
| AUTH-001 | 이메일 입력 | 사용자는 회원가입용 이메일을 입력한다. | 이메일/비밀번호 로그인만 제공, 이메일 형식 필수 | 형식 오류 시 즉시 안내 |
| AUTH-002 | 인증 코드 발송 | 입력된 이메일로 인증 코드를 전송한다. | 재전송 최소 1분 간격, 인증 코드 만료 5분 | 전송 실패 시 재시도 안내 |
| AUTH-003 | 인증 코드 입력 및 검증 | 사용자는 인증 코드를 입력하고 검증 요청한다. | 최대 5회 시도 제한 | 실패 시 재입력 유도 |
| AUTH-004 | 인증 제한 처리 | 인증 시도 초과 시 입력을 차단한다. | 5회 초과 시 15분 차단 | 차단 안내 메시지 표시 |
| AUTH-005 | 회원 정보 입력 | 인증 완료 후 이름과 비밀번호를 입력한다. | 인증 완료 후 가능 | 필수 값 누락 시 다음 단계 이동 불가 |
| AUTH-006 | 비밀번호 검증 | 비밀번호와 확인 값 일치 여부를 검증한다. | 최소 8자, 대소문자 혼합, 숫자 1개 이상, 특수문자 1개 이상 | 불일치 또는 정책 미충족 시 오류 메시지 출력 |
| AUTH-007 | 가입 완료 | 회원 정보를 저장하고 가입 완료 처리한다. | 모든 검증 성공 시 가능 | 저장 실패 시 오류 안내 |
| AUTH-008 | 가입 성공 안내 | 회원가입 완료 메시지를 표시한다. | 없음 | 없음 |
| AUTH-009 | 내 정보 조회 | 프로필에서 이름과 이메일을 조회한다. | 로그인 필요 | 조회 실패 시 오류 안내 |
| AUTH-010 | 비밀번호 변경 | 마이페이지에서 이메일 인증 후 비밀번호를 변경한다. | 이메일 인증번호 확인 필요 | 인증번호 오류 시 변경 불가 |

## 메인페이지

| ID | 기능 | 요구사항 | 제약 | 예외 처리 |
| --- | --- | --- | --- | --- |
| MAIN-001 | 프로젝트 생성 버튼 | 사용자는 메인페이지에서 프로젝트 생성 버튼을 클릭한다. | 로그인 필요 | 생성 화면 이동 실패 시 오류 |
| MAIN-002 | 프로젝트 목록 조회 | 사용자는 자신이 참여한 프로젝트 목록을 조회한다. | 로그인 필요 | 목록 조회 실패 시 오류 |
| MAIN-003 | 캘린더 화면 | 사용자는 캘린더에서 모든 프로젝트 일정 항목을 확인한다. | 로그인 필요, 프로젝트별 색상 구분 필요, 완료 상태와 진행률은 표시하지 않음 | 일정 조회 실패 시 오류 |

## 프로젝트 생성

| ID | 기능 | 요구사항 | 제약 | 예외 처리 |
| --- | --- | --- | --- | --- |
| PROJ-001 | 프로젝트 이름 입력 | 리더는 프로젝트 이름을 입력한다. | 1자 이상 24자 이하 | 프로젝트 생성 실패 시 에러 토스트 |
| PROJ-002 | 프로젝트 유형 선택 | 리더는 개인 또는 팀 프로젝트를 선택한다. | personal 또는 team 중 하나 필수 | 미선택 시 오류 메시지 |
| PROJ-003 | 아이디어 입력 | 리더는 간단한 프로젝트 아이디어를 입력한다. | 필수, 최소 200자 이상, 공백 포함 기준 | 미입력 또는 길이 부족 시 오류 메시지 |
| PROJ-004 | AI 아이디어 증강 | 리더는 AI 아이디어 증강 버튼으로 아이디어를 구체화하고 결과를 직접 수정할 수 있다. | 클릭 1회만 가능 | 호출 실패 시 프론트에서 에러 표시 |
| PROJ-005 | 시작 날짜 입력 | 리더는 프로젝트 시작 날짜를 입력한다. | 필수 | 미입력 시 오류 메시지 |
| PROJ-006 | 종료 날짜 입력 | 리더는 프로젝트 종료 날짜를 입력한다. | 필수, 종료일 - 시작일 최대 365일 | 미입력 또는 기간 초과 시 오류 메시지 또는 모달 |
| PROJ-007 | 멤버 이메일 초대 | 리더는 팀 프로젝트에서 팀원 이메일을 입력해 초대한다. | 개인 프로젝트에서는 초대 UI 미표시, 같은 프로젝트 내 중복 초대 방지, 미가입 이메일 초대 가능, 동일 이메일의 여러 프로젝트 동시 초대 가능, 초대 만료 7일 | 이미 초대된 사람에게는 재발송하지 않음 |
| PROJ-008 | 프로젝트 생성 완료 | 생성 완료 메시지를 표시하고 AI 문서 초안을 동기 생성한다. | 기능 명세 저장 본문 2000자 이하, API 명세 담당자 없음, API 명세 길이 제한 없음 | AI 문서 생성 실패 시 프로젝트는 생성하고 문서 기본값 `AI 호출이 실패했어요 프로젝트에 대한 설명을 적어주세요` 적용 |

## 프로젝트 참여

| ID | 기능 | 요구사항 | 제약 | 예외 처리 |
| --- | --- | --- | --- | --- |
| INV-001 | 프로젝트 초대 수락 | 멤버는 초대를 수락하고 전공, 기술 스택, 요일/시간대 기준 참여 가능 시간을 입력한다. | 리더는 생성 이후 바로 표시 | 필수 정보 누락 시 수락 완료 불가 |
| INV-002 | 프로젝트 초대 거부 | 멤버는 초대를 거부할 수 있다. | pending 상태 멤버 삭제, 초대 이메일 만료 | 이미 처리된 초대는 재처리 불가 |
| INV-003 | 멤버 초대 상태 조회 | 리더는 멤버의 초대 상태를 확인한다. | 프로젝트 리더 권한 필요 | 조회 실패 시 오류 |

## 기능 명세서 관리

| ID | 기능 | 요구사항 | 제약 | 예외 처리 |
| --- | --- | --- | --- | --- |
| FS-001 | 기능 명세서 조회 | 사용자는 AI가 생성한 기능 명세서를 확인한다. | 프로젝트 접근 권한 필요 | 조회 실패 시 오류 |
| FS-002 | 기능 명세서 직접 수정 | 모든 프로젝트 멤버는 기능 명세서를 직접 수정한다. | 저장 본문 2000자 이하 | 길이 초과 시 저장 불가 |
| FS-003 | 기능 명세서 AI 수정 | 모든 프로젝트 멤버는 요청을 입력해 AI가 기능 명세서를 수정하게 한다. | 저장 본문 2000자 이하, AI 수정 요청 이력 보관 | AI 호출 실패 시 기존 문서 유지 |

## 일정 관리

| ID | 기능 | 요구사항 | 제약 | 예외 처리 |
| --- | --- | --- | --- | --- |
| SCH-001 | 일정 생성 | AI는 팀원 전공, 기술 스택, 요일/시간대 기준 참여 가능 시간을 바탕으로 일정을 생성한다. | 날짜 단위 일정, 역할 분담, 스프린트 단위 회의, 시작일과 마감일 반환, 스프린트 기간은 프로젝트 기간에 따라 AI가 결정 | 생성 실패 시 오류 |

| SCH-004 | 일정 AI 수정 | 프로젝트 리더는 요청을 입력해 AI로 일정을 수정한다. | 날짜 단위, 프로젝트 기간 범위 준수, AI 수정 요청 이력 보관 | AI 호출 실패 시 기존 일정 유지 |
