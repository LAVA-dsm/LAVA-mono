## 구현 의존성 메모

- AI 문서 초안 생성은 프로젝트 생성 데이터가 저장된 뒤 동기 실행되어야 합니다.
- AI 문서 초안 생성이 실패해도 프로젝트는 생성하고 fallback 문구를 저장합니다.
- 일정 생성은 멤버 참여 정보가 충분히 수집된 뒤 실행되어야 합니다.
- 캘린더 조회는 일정 생성과 일정 조회 기능 이후에 구현하는 것이 자연스럽습니다.
- 회원가입이 4차 스프린트로 배치되어 있지만 실제 서비스 구현에서는 인증 기반이 먼저 필요할 수 있습니다.
- 이메일 초대는 미가입 사용자에게도 보낼 수 있습니다.
- 일정 직접 수정과 일정 AI 수정은 리더만 가능합니다.
