# 프로젝트 브리프

## 프로젝트명

LAVA

## 프로젝트 주제

AI 기반 프로젝트 기획 및 협업 도우미

## 한 줄 정의

사용자가 프로젝트 아이디어를 입력하면 AI가 이를 구체화하고 일정, 기능 명세서, API 명세서까지 자동 생성해주는 프로젝트 시작 지원 서비스입니다.

## 해결하려는 문제

프로젝트를 시작하는 개인이나 팀은 보통 아래 지점에서 막힙니다.

- 아이디어는 있지만 구체화가 어렵다.
- 어떤 기능부터 넣어야 할지 모른다.
- 일정 산정이 어렵다.
- 팀원 수, 전공, 기술 스택, 참여 가능 시간을 반영한 계획을 세우기 어렵다.
- API 명세서와 기능 명세서를 처음부터 작성하기 부담스럽다.

## 해결 방식

사용자가 프로젝트 기본 정보를 입력하면 AI가 다음 산출물을 생성하거나 보조합니다.

- 프로젝트 아이디어 구체화
- 기능 구조 제안
- 개발 일정 생성
- 기능 명세서 초안 생성
- API 명세서 초안 생성

## 1차 타겟 사용자

- 대학생 팀 프로젝트 사용자
- 기획서 작성이 익숙하지 않은 주니어 개발자
- 협업 경험이 적은 팀

## 핵심 가치 제안

### 1. 아이디어를 실행 가능한 계획으로 변환

막연한 아이디어를 실제 개발 문서와 일정 형태로 바꿉니다.

### 2. 팀 상황에 맞춘 계획 제공

팀원의 전공, 기술 스택, 참여 가능 시간, 프로젝트 기간을 반영합니다.

### 3. 프로젝트 시작 시간 단축

초기 기획 시간을 줄이고 바로 개발에 들어갈 수 있는 초안을 제공합니다.

## 핵심 기능

### 아이디어 구체화

입력된 아이디어를 AI가 분석해 아래 항목으로 정리합니다.

- 프로젝트 목적
- 핵심 사용자
- 주요 기능
- 차별점
- 예상 개발 범위

### 문서 자동 생성

AI가 개발에 바로 참고할 수 있는 초안 문서를 생성합니다.

- 기능 명세서
- API 명세서
- 일정표

## 제품 범위 요약

LAVA의 초기 제품은 프로젝트 생성, 팀원 초대, AI 문서 생성, AI 일정 생성, 문서와 일정의 직접 수정 및 AI 수정에 집중합니다. 채팅은 생성 결과를 후속 조정하는 대화형 수정 수단으로 정의됩니다.
