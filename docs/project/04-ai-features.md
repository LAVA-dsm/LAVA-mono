# AI 기능 요구사항

AI 기능은 일반 CRUD와 별도로 다룹니다. 각 기능은 입력, 출력, 제한, 실패 처리를 명확히 가져야 합니다.

## 공통 정책

- AI 응답은 동기 처리합니다.
- AI 수정 요청 이력은 보관합니다.
- AI 결과 버전 관리는 제공하지 않습니다.

## AI-IDEA-001: 아이디어 증강

### 목적

사용자가 입력한 프로젝트 아이디어를 프로젝트 개요로 구체화합니다.

### 트리거

프로젝트 생성 화면에서 사용자가 `AI 아이디어 증강` 버튼을 클릭합니다.

### 입력

- 프로젝트 이름
- 프로젝트 유형: 개인 또는 팀
- 사용자가 입력한 원본 아이디어
- 프로젝트 시작일
- 프로젝트 종료일

### 출력

증강된 아이디어는 아래 구조를 포함해야 합니다.

- 프로젝트 목적
- 핵심 사용자
- 주요 기능
- 차별점
- 예상 개발 범위

### 제한

- 프로젝트 생성 중 1회만 실행할 수 있습니다.
- 실행 후 버튼은 비활성화 상태로 표시합니다.
- 원본 아이디어 입력값은 보존합니다.
- 증강 결과는 사용자가 직접 수정할 수 있습니다.

### 실패 처리

- AI 호출 실패 시 프론트에서 오류를 표시합니다.
- 실패해도 사용자의 입력 상태는 유지합니다.

## AI-DOC-001: 기능 명세서 초안 생성

### 목적

프로젝트 생성 완료 시 개발에 참고할 기능 명세서 초안을 생성합니다.

### 트리거

프로젝트 생성 완료 직후 동기 실행합니다.

### 입력

- 프로젝트 기본 정보
- 원본 아이디어
- 증강된 아이디어가 있으면 해당 내용
- 프로젝트 유형
- 프로젝트 기간
- 팀원 초대 정보

### 출력

기능 명세서 초안은 기능명, 설명, 제약사항, 예외 처리를 포함해야 합니다.

### 제한

- 기능 명세서 본문은 저장 본문 기준 2000자 이하입니다.

### 실패 처리

- 생성 실패 시 프로젝트 자체는 생성합니다.
- 기능 명세서에는 기본값 `AI 호출이 실패했어요 프로젝트에 대한 설명을 적어주세요`를 적용합니다.
- 사용자에게 에러를 표시합니다.

## AI-DOC-002: API 명세서 초안 생성

### 목적

프로젝트 생성 완료 시 API 명세서 초안을 생성합니다.

### 트리거

프로젝트 생성 완료 직후 동기 실행합니다.

### 입력

- 프로젝트 기본 정보
- 원본 아이디어
- 증강된 아이디어가 있으면 해당 내용
- 기능 명세서 초안

### 출력

API 명세서 초안은 아래 정보를 포함하는 것을 권장합니다.

- API 이름
- HTTP 메서드
- 경로
- 요청 데이터
- 응답 데이터

### 제한

- API 명세서에는 길이 제한을 두지 않습니다.

### 실패 처리

## AI-SCH-001: 프로젝트 일정 생성

### 목적

팀원의 전공, 기술 스택, 참여 가능 시간을 반영해 실행 가능한 프로젝트 일정을 생성합니다.

### 트리거

프로젝트 메인에서 일정 생성 기능을 실행합니다.

### 입력

- 프로젝트 시작일
- 프로젝트 종료일
- 프로젝트 아이디어 또는 증강 아이디어
- 기능 명세서
- 멤버 전공
- 멤버 기술 스택
- 멤버 참여 가능 시간: 요일/시간대 형식

### 출력

일정은 아래 내용을 포함해야 합니다.

- 역할 분담
- 스프린트 단위 작업 구성
- 회의 일정
- 각 항목의 시작일
- 각 항목의 마감일

### 제한

- 일정 항목은 날짜 단위로 생성합니다.
- 모든 일정은 프로젝트 시작일과 종료일 사이에 있어야 합니다.
- 스프린트 기간은 고정하지 않고 프로젝트 기간에 따라 AI가 결정합니다.
- 회의 시간이 충분히 겹치지 않으면 리더가 가능한 시간을 기준으로 다른 멤버들의 시간대를 고려해 가장 겹치는 날이 많은 곳에 배정합니다.

### 실패 처리

- 생성 실패 시 사용자에게 오류를 표시합니다.
- 기존 일정이 있으면 유지합니다.

## AI-SCH-002: 프로젝트 일정 AI 수정

### 목적

사용자 요청을 반영해 기존 프로젝트 일정을 조정합니다.

### 입력

- 현재 일정

### 출력

- 수정 후에도 모든 일정은 날짜 단위이며 프로젝트 기간 안에 있어야 합니다.
- AI 수정 요청 이력은 보관합니다.

### 실패 처리

- AI 호출 실패 시 기존 일정을 유지합니다.
- 사용자에게 오류를 표시합니다.
