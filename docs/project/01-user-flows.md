# 사용자 흐름

## 전체 서비스 흐름

1. 사용자는 이메일/비밀번호 기반 회원가입 또는 로그인을 진행합니다.
2. 프로젝트 리더는 프로젝트를 생성합니다.
3. 리더는 프로젝트 기본 정보와 아이디어를 입력합니다.
4. 리더는 필요하면 AI 아이디어 증강을 1회 실행하고, 증강 결과를 직접 수정할 수 있습니다.
5. 리더는 팀 프로젝트인 경우 팀원 이메일을 입력해 초대합니다. 개인 프로젝트에서는 멤버 초대 UI를 표시하지 않습니다.
6. 프로젝트 생성 완료 시 AI가 기능 명세서와 API 명세서 초안을 동기 생성합니다.
7. AI 문서 생성이 실패해도 프로젝트는 생성되고 문서에는 기본 안내 문구가 적용됩니다.
8. 초대받은 멤버는 초대를 수락하거나 거부합니다.
9. 수락한 멤버는 전공, 기술 스택, 요일/시간대 기준 참여 가능 시간을 입력합니다.
10. AI는 멤버 정보를 바탕으로 역할 분담과 스프린트 일정을 날짜 단위로 생성합니다.
11. 사용자는 프로젝트 메인에서 기능 명세서, API 명세서, 일정을 조회하고 수정합니다.
12. 사용자는 AI에게 추가 요청을 보내 문서나 일정을 조정합니다.

## 회원가입 흐름

1. 이메일 입력
2. 이메일 형식 검증
3. 인증 코드 발송
4. 인증 코드 입력
5. 인증 코드 검증
6. 이름과 비밀번호 입력
7. 비밀번호 확인 값 검증
8. 가입 완료
9. 가입 성공 안내

## 프로젝트 생성 흐름

1. 프로젝트 생성 버튼 클릭
2. 프로젝트 이름 입력
3. 개인 또는 팀 프로젝트 선택
4. 프로젝트 아이디어 입력
5. AI 아이디어 증강 선택 가능
6. 시작 날짜 입력
7. 종료 날짜 입력
8. 팀 프로젝트인 경우 멤버 이메일 초대. 개인 프로젝트에서는 이 단계가 없습니다.
9. 프로젝트 생성 완료
10. AI 기능 명세서와 API 명세서 초안 생성

## 프로젝트 참여 흐름

### 초대 수락

1. 멤버가 이메일 초대 링크를 엽니다.
2. 프로젝트 초대를 수락합니다.
3. 자신의 전공을 입력합니다.
4. 기술 스택을 입력합니다.
5. 요일/시간대 기준 참여 가능 시간을 입력합니다.
6. 프로젝트 멤버 상태가 참여 완료로 변경됩니다.

### 초대 거부

1. 멤버가 이메일 초대 링크를 엽니다.
2. 프로젝트 초대를 거부합니다.
3. pending 상태의 멤버 정보가 제거됩니다.
4. 해당 초대 이메일 또는 초대 링크는 만료됩니다.

## 프로젝트 메인 흐름

프로젝트 메인은 생성된 산출물을 확인하고 조정하는 공간입니다.

- 기능 명세서 조회
- 기능 명세서 직접 수정
- 기능 명세서 AI 수정
- API 명세서 조회
- API 명세서 직접 수정
- API 명세서 AI 수정
- 일정 생성
- 일정 조회
- 일정 직접 수정
- 일정 AI 수정

문서 조회와 문서 직접 수정은 모든 프로젝트 멤버가 사용할 수 있습니다. 일정 직접 수정과 일정 AI 수정은 프로젝트 리더만 사용할 수 있습니다.

## 메인페이지 흐름

로그인한 사용자는 메인페이지에서 아래 기능을 사용합니다.

- 프로젝트 생성
- 참여 프로젝트 목록 조회
- 캘린더 기반 전체 일정 항목 확인
- 프로필 클릭 후 내 정보 조회
- 이메일 인증 후 비밀번호 변경

## 프로젝트 나가기 흐름

### 일반 멤버 나가기

1. 멤버가 프로젝트 정보 관리에서 나가기를 선택합니다.
2. 멤버 상태가 left로 변경됩니다.

### 리더 나가기

1. 리더가 프로젝트 나가기를 선택합니다.
2. 리더는 나가기 전에 새 리더를 직접 선택합니다.
3. 리더 권한이 위임된 뒤 기존 리더의 멤버 상태가 left로 변경됩니다.
